# Word Farm MiniAnt Package

This folder contains a MiniAnt-compatible static package reconstructed from the supplied `Word Farm.har` capture.

Run locally:

```bash
npm install
npm run build
npm run preview
```

The build output is `./dist`. The MiniAnt SDK is loaded from `https://www.miniant.games/sdk/v1.js`; standalone local preview runs only when the page is not embedded.
